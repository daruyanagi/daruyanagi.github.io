プライバシーポリシー

このプライバシーポリシーは、だるやなぎ（柳 英俊、以下「開発者」）が提供するアプリケーション・ブラウザー拡張機能（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

対象となる主なアプリは次のとおりです。

  • XTimelineViewer（xTV）
  • Petapeta
  • Kataomoi（ Google Chrome 拡張機能）
  • そのほか、開発者が GitHub などで公開しているアプリ

1. 開発者が収集する情報 見出しへのリンク

本アプリは、利用者の個人情報を開発者のサーバーへ送信・収集しません。 開発者は利用者を識別するためのアカウント登録を求めず、アクセス解析・広告・行動トラッキングのための仕組みも本アプリには組み込んでいません。

2. 利用者の端末に保存される情報 見出しへのリンク

本アプリは、動作に必要な情報を利用者の端末内にのみ保存します。これらは開発者を含む第三者へ送信されません。

  • 設定値（テーマ、表示設定、オン/オフの状態など）
  • 動作ログ（アプリによっては、処理したファイル名などを含みます）
  • アプリが生成した一時ファイル

アプリごとの補足は次のとおりです。

XTimelineViewer（xTV） 見出しへのリンク

  • xTV は Microsoft Edge WebView2 を利用して X（旧 Twitter）の Web ページを表示します。X へのログイン情報や Cookie などは、 WebView2 のプロファイルとして利用者の端末内に保存されます。開発者がこれらを取得することはありません。
  • X の Web ページの表示・操作に伴う通信は、利用者と X Corp. との間で直接行われます。その取り扱いについては X のプライバシーポリシー をご確認ください。
  • 「 GitHub からインストール」機能やアップデートの確認を利用すると、 GitHub のサーバーとの通信が発生します。

Petapeta 見出しへのリンク

  • クリップボードを監視し、コピーされた画像やテキストを端末内の「ステージングフォルダー」にファイルとして書き出します。テキストのファイル化を有効にしている場合、コピーしたテキスト（パスワードなどを含む場合があります）が一時的にディスクへ保存されます。不要な場合は設定でオフにしてください。
  • ステージングフォルダーやログは、設定した保持期間・件数に従って自動削除されます。
  • 「画像 URL をダウンロードしてファイル化」が有効な場合、コピーしたテキストが画像の URL と判断されると、その URL への通信が発生します。

Kataomoi 見出しへのリンク

  • X の Web ページに表示されている内容と、ページがすでに受け取っているデータを、ブラウザー内で読み取って表示に利用します。Kataomoi 自身が X や外部のサーバーへリクエストを送ることはありません。
  • 設定は Chrome の拡張機能用ストレージ（chrome.storage）に保存されます。 Chrome の同期機能を有効にしている場合は、 Google アカウントを通じて同期されることがあります。
  • 読み取ったデータを開発者や第三者へ送信・販売・共有することはありません。また、拡張機能の目的（片思いユーザーの表示）以外には利用しません。

3. 外部サービスとの通信 見出しへのリンク

本アプリの機能によっては、 X、 GitHub、 Microsoft、 Google などの外部サービスとの通信が発生します。これらの通信で送られる情報の取り扱いは、各サービスのプライバシーポリシーに従います。また、本アプリの配布元（ GitHub、 winget、 Chrome ウェブストアなど）がダウンロード数などの統計を収集する場合があります。

4. 情報の削除 見出しへのリンク

本アプリが端末内に保存した情報は、アプリのアンインストール、または各アプリのデータフォルダーの削除によって消去できます。ブラウザー拡張機能の設定は、拡張機能を削除すると消去されます。

5. 本ポリシーの変更 見出しへのリンク

開発者は、必要に応じて本ポリシーを変更することがあります。変更後のポリシーは、このページに掲載した時点から効力を生じます。

6. お問い合わせ 見出しへのリンク

本ポリシーに関するお問い合わせは、各アプリの GitHub リポジトリの Issues、または X（@daruyanagi） までお寄せください。
